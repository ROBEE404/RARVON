# Rarvon logo, final

The raven R: an R whose top is a raven's head, cut from three paper layers, with an angry amber eye,
a white glint and a flicked amber brow.

## Which file for what

| Need | File |
|---|---|
| Logo with the name, on a **light** background | `svg/rarvon-logo-for-light.svg` (letters as shapes, no font needed), `png/rarvon-logo-for-light@2x.png` (1x, 2x, 4x) |
| Logo with the name, on a **dark** background | `svg/rarvon-logo-for-dark.svg` (letters as shapes, no font needed), `png/rarvon-logo-for-dark@2x.png` (1x, 2x, 4x) |
| The raven alone, on light | `svg/rarvon-mark-for-light.svg`, `png/rarvon-mark-for-light-*.png` |
| The raven alone, on dark | `svg/rarvon-mark-for-dark.svg`, `png/rarvon-mark-for-dark-*.png` |
| App icon (rounded, deep violet) | `svg/rarvon-app-icon.svg`, `png/rarvon-app-icon-*.png` (16 to 1024 px) |
| Phone and install icon (full square) | `svg/rarvon-app-icon-maskable.svg`, `png/rarvon-app-icon-maskable-*.png` |
| iPhone home screen | `png/rarvon-app-icon-180.png` |
| Windows (program, shortcut, installer) | `rarvon.ico` (16 to 256 px inside) |

## Colours

| Colour | Hex | Used for |
|---|---|---|
| Deep violet | `#26213A` | App icon background |
| Amber | `#F2A33A` | Eye, beak, brow, back paper layer |
| Violet | `#9B85FF` | Middle paper layer, eye shadow |
| Lavender | `#E6E2F7` | The raven's face on dark backgrounds |
| Ink | `#1B1B22` | The raven's body and the name on light backgrounds |
| Off-white | `#F1F0F5` | The name on dark backgrounds |

## Type

The name is **RARVON** in **Syne ExtraBold (800)**, all capitals, letter spacing about 0.08 em.
Syne is free (SIL Open Font License): https://fonts.google.com/specimen/Syne

## Don'ts

- Don't stretch, rotate or recolour the raven.
- Keep clear space around it of at least the width of the eye.
- On light backgrounds use the "for-light" files; on dark backgrounds the "for-dark" files.
