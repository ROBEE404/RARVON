# Security Policy

Rarvon processes files entirely in the browser for every tool marked as available — nothing is
uploaded to a server for those tools, so there's no server-side file-handling surface to attack for
them.

If you find a security issue (e.g. a way a tool could be tricked into making a network request with
file contents, or an XSS vector), please open an issue or contact the maintainer directly rather than
disclosing it publicly first.
